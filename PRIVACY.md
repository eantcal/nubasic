# Privacy policy

This policy applies to nuBASIC, including the command-line interpreter, the
IDE, and the packages distributed through GitHub Releases and the Microsoft
Store.

## Data collection

nuBASIC does not collect telemetry, analytics, crash reports, or any other
personal data, and it does not transmit data automatically.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

## Programs you run

Programs executed through nuBASIC can access files, launch commands, or call
native libraries when explicitly instructed by their source code and allowed
by the operating system. Any data such a program reads, stores, or sends is
under the control of that program and of the user who runs it, not of the
nuBASIC project.

Users should review untrusted BASIC programs before running them; native
library calls can be disabled with `--disable-native-calls`.

## Contact

Questions about this policy can be raised through the
[public issue tracker](https://github.com/eantcal/nubasic/issues).
Security-sensitive issues should follow the [security policy](SECURITY.md).
